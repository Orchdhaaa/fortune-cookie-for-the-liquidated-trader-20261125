One fortune cookie line for a crypto trader who just got liquidated: "Your lucky numbers are 0, 0, 0, and the margin call you ignored." The classic cookie trope is lucky numbers; here every lucky number is zero, and the punchline names the margin call the trader ignored. Oracular opening, joke that lands on the loss.

## Run it

```sh
node main.ts
```

`main.ts` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is one line of at most 20 words and 1–160 characters with no dash, and that it names the trading loss.
